# .github

This repository owns Agentic Tend's organization profile, shared community health files, cross-layer public documentation, and versioned sources for small user-level defaults.

## Project map

- [Organization profile](profile/README.md) is the public landing page shown on the organization overview.
- [Organization docs](docs/README.md) are the canonical map for principles, capability topology, human-facing presentation, context ownership, evaluation, and the cross-layer roadmap.
- [Codex global defaults](config/codex/AGENTS.global.md) are the versioned source for the L0 interaction contract installed at `~/.codex/AGENTS.md`.

Repository-specific instructions, implementation, user documentation, and roadmaps remain in the repository that owns them. Runtime configuration, credentials, sessions, logs, permission rules, and databases are not versioned here.
