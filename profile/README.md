# Agentic Tend

Agentic Tend develops lightweight, composable layers for tending agentic software development.

`Tend` means caring for a growing system: add structure when evidence calls for it, keep each layer composable, and let projects retain their own shape.

## Layers

- [**Rules**](https://github.com/agentic-tend/copier-coding-harness): a language-independent, contract-first repository harness distributed as a Copier template.
- [**Skills**](https://github.com/agentic-tend/skills): reusable, on-demand workflows that remain separate from repository rules.
- **Hooks:** a future extension point for concrete event and enforcement contracts.

## Approach

- Establish contracts before implementation.
- Grow structure from observed needs and recurring failures.
- Keep rules, skills, and hooks distinct by activation and enforcement.
- Prefer small, composable layers over monolithic agent configurations.
