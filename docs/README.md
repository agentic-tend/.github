# Organization documentation

This directory owns public contracts shared across Agentic Tend's tooling layers.

## Map of contents

- [Agentic tooling](agentic-tooling.md) defines the motivation, task data and dispatch metadata loop, capability composition, intellectual influences, and evaluation model.
- [Context ownership](context-ownership.md) defines persistence thresholds, placement, activation and enforcement, canonical sources, and migration pressure tests.
- [Development](development.md) gives human-facing capability-composition scenarios without prescribing a fixed workflow.
- [Roadmap](roadmap.md) tracks milestones that coordinate or compare more than one layer.

Layer-specific implementation, instructions, and delivery plans remain in their owning repositories.
