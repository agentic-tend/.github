# Organization documentation

This directory owns public contracts shared across Agentic Tend's tooling layers.

## Map of contents

- [Agentic tooling](agentic-tooling.md) defines the motivation, knowledge and evidence flow, activation mechanisms, intellectual influences, and evaluation model.
- [Context ownership](context-ownership.md) defines operational placement, consistency diagnosis, and migration pressure tests.
- [Development](development.md) is the human-facing cognitive model for routing contract, planning, durable work, execution, and verification.
- [Roadmap](roadmap.md) tracks milestones that coordinate or compare more than one layer.

Layer-specific implementation, instructions, and delivery plans remain in their owning repositories.
